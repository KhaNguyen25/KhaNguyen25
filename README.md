## 🚀 Featured Projects

### 📈 [Vietnamese ETF Price Forecasting](https://github.com/KhaNguyen25/Predict-ETF-Prices-In-Vietnam)
**Python · scikit-learn · XGBoost · TensorFlow/Keras · ARIMA/SARIMA**

A comparative study of statistical, machine learning, and deep learning approaches to forecasting Vietnamese ETF prices.

- Collected and prepared historical price data for **six Vietnamese ETFs**.
- Compared **nine forecasting models**, including ARIMA/SARIMA, XGBoost, SVR, KNN, linear regression, LSTM, GRU, and TCN.
- Evaluated predictive performance with **MAE, RMSE, MAPE, and directional accuracy**.

[**Explore repository →**](https://github.com/KhaNguyen25/Predict-ETF-Prices-In-Vietnam)

### 🌌 [Astronomical Source Classification](https://github.com/KhaNguyen25/Classification-of-Astronomical-Sources)
**Python · Pandas · scikit-learn · XGBoost · UMAP · Datashader**

Classification and visualization of celestial objects using large-scale photometric data.

- Performed exploratory data analysis on **3.1 million labeled objects** from SDSS DR15.
- Compared classification approaches including **Logistic Regression, Random Forest, and XGBoost**.
- Applied the trained classification workflow to a separate dataset of approximately **111 million unlabeled sources**, with 2D visual exploration using UMAP.

[**Explore repository →**](https://github.com/KhaNguyen25/Classification-of-Astronomical-Sources)

### 💳 [Financial Transaction Analytics & Fraud Detection](https://github.com/KhaNguyen25/OLAP_SSIS_SSAS)
**SQL Server · SSIS · SSAS · MDX · Power BI · Python · XGBoost**

An end-to-end data warehousing and analytics project using financial transaction data.

- Designed a **star-schema data warehouse** and SSIS ETL workflows for **over 13 million transaction records**.
- Built **SSAS OLAP cubes** and MDX queries to study transaction trends and customer behavior.
- Created **Power BI and Looker Studio dashboards** and explored machine learning approaches to fraud detection.

[**Explore repository →**](https://github.com/KhaNguyen25/OLAP_SSIS_SSAS)
